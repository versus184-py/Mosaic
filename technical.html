Architecture

Mosaic is a Tauri v2 desktop app with a React 19 frontend and a Rust backend. The frontend manages the branching canvas, provider routing, and code sandbox, while the backend handles window management, file system access, and native OS integration.

The canvas uses React Flow v12 for the node-graph UI. Each message is a node in a directed tree. Branches fork from any parent node, creating a DAG structure that allows arbitrary branching depth.

Provider Layer

All five providers share a common streaming abstraction via a generic streamProvider adapter that normalizes differences in API signatures, error handling, and token streaming.

ProviderStreamModelsEmbedding
MistralReadableStream via fetchmistral-small, -medium, -large✓
OpenAIOpenAI SDK streamGPT-4o, GPT-4o-mini, o3-mini✓
AnthropicAnthropic SDK streamClaude 3.5 Sonnet, Haiku✗
GeminiGenAI SDK streamGemini 2.0 Flash, Pro✗
OllamaREST /api/chat streamAny local model✓

Each provider adapter implements a common ProviderAdapter interface with methods for streamChat, embedTexts, and detectModels. The useOllamaDetect hook returns { checking, retry, connected } to manage Ollama connection state.

RAG Pipeline

Mosaic supports retrieval-augmented generation using local embeddings. The pipeline chunks documents, embeds them with the selected provider, and injects relevant context into the prompt.

Document ──> Chunk ──> Embed ──> Store ──> Query
                                    │
                                    v
                              Rank chunks ──> Inject into prompt

Embeddings are fetched via embedTexts which returns number[][] | null. The function never throws — it returns null on failure for graceful degradation. Cosine similarity ranks chunks, and the top-k are prepended to the system prompt.

Code Sandbox

Python execution runs entirely in-browser via Pyodide, a WebAssembly build of CPython 3.12. No code leaves your machine. The sandbox includes 50+ pre-installed packages including NumPy, Pandas, Matplotlib, and SymPy.

Execution is asynchronous — the UI remains responsive while Python runs. Output (stdout + stderr) is streamed back into the canvas as a child node of the code block. JavaScript execution uses Web Workers as an alternative sandbox.

Build Guide

# Prerequisites: Node.js 20+, Rust 1.83+, Tauri CLI
npm install
npm run tauri dev     # Development with hot-reload
npm run build         # Prod build (JS + Rust)
npm run tauri build   # Desktop binaries (Win/Mac/Linux)

CI/CD runs on GitHub Actions with a Win/Mac/Linux matrix. ci.yml handles lint + typecheck + test coverage, and release.yml produces platform-specific installers on tag push.

Security Model

  • API keys are stored in localStorage — never sent to any server except the provider's API endpoint
  • Pyodide sandbox is fully isolated — no access to the file system, network, or OS APIs
  • All provider communication is over HTTPS with TLS 1.3
  • Ollama traffic stays on localhost:11434 — never leaves your machine
  • No telemetry, no analytics, no data collection
  • Auto-updates via Tauri updater with signature verification
