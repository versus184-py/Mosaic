CRDT-based approach with Yjs or Automerge is the gold standard. Yjs uses a performant algorithm with minimal overhead. Pair it with WebRTC or WebSocket providers for real-time sync.

For a simpler approach, consider using a central WebSocket server with last-writer-wins. Each operation is an event: { type: 'draw', data: {...} }. Works well for under 10 concurrent users.
