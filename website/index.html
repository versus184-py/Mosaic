FAQ

Common questions

Everything you need to know about Mosaic.

Do I need an API key for every provider?
Yes, each provider requires its own API key. Bring your own keys and manage them through Mosaic's settings panel. Keys are stored locally on your machine and never sent anywhere except the provider's API endpoint.
Can I use Mosaic offline?
Yes, with Ollama. Point Mosaic at your local Ollama instance and run any supported model completely offline with zero data leaving your machine. Cloud providers require internet access.
Does Mosaic support streaming responses?
Yes. All providers stream responses token-by-token. Mosaic normalizes streaming across providers so you get real-time output regardless of which model you choose, with a unified event system.
What is the code sandbox?
Mosaic embeds Pyodide, a Python 3.12 runtime compiled to WebAssembly, to execute code directly in the app. No server needed — results appear instantly in the canvas. Includes 50+ pre-installed packages like NumPy, Pandas, and Matplotlib.
Is Mosaic open source?
Yes, Mosaic is fully open source under the MIT license. The entire codebase is available on GitHub for inspection, contribution, and self-hosting. 191 tests pass across 11 test suites.
