# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a vulnerability

If you discover a security vulnerability in Mosaic, please report it privately before disclosing it publicly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, send a description of the issue to the project maintainers via one of these channels:

- Open a **private security advisory** at [github.com/versus184-py/Mosaic/security/advisories/new](https://github.com/versus184-py/Mosaic/security/advisories/new)
- Or reach out directly via a GitHub issue (mark it as sensitive if the platform supports it)

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Your assessment of the potential impact
- Any suggested fix (if you have one)

You should receive an acknowledgment within 72 hours, and we'll keep you updated as we work on a fix.

## Scope

This policy applies to the Mosaic desktop application and its source code (both the TypeScript/React frontend and the Rust/Tauri backend). Third-party dependencies should be reported to their respective maintainers.

## Preferences

We appreciate coordinated disclosure. Please give us reasonable time to fix and release a patched version before publishing details publicly.
