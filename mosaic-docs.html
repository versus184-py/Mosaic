App Features

Built for depth

Every feature designed to accelerate exploration and reasoning.

Branching canvas

Non-linear conversation tree. Fork any node, explore tangents, never lose your thread.

⚙

Model routing

Route prompts to Mistral, OpenAI, Anthropic, Gemini, or Ollama from one interface.

☰

Side-by-side compare

Send the same prompt to multiple providers and compare responses in split view.

RAG embeddings

Inject context from your own documents using local embedding models.

✓

Code sandbox

Python execution in-browser via Pyodide (WASM) — no server needed, instant feedback.

◎

Local-first

All data stays on your machine. Works offline with Ollama for complete privacy.
